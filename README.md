# 大尾巴闪念 PC 版

## 1. 项目概况

- 项目类型：Windows 轻量软件 / 本地自动化工具
- 当前版本：v0.4.1（修复三组快捷键开关与输入框高度不齐）
- 开发技术：AutoHotkey v2
- 最终交付：可直接阅读和修改的 `.ahk` 源码，不编译 EXE
- 使用对象：大尾巴
- 核心目标：复制内容后，通过全局快捷键保存为普通闪念、待办，或新建一篇独立 Obsidian 笔记；网页复制内容自动携带来源网址。

## 2. 已确定的产品形态

程序以 AutoHotkey v2 脚本运行，常驻 Windows 托盘，并提供一个简单设置界面。

默认快捷键：

| 快捷键 | 功能 | 结果 |
| --- | --- | --- |
| `Ctrl + Alt + S` | 保存普通闪念 | 默认启用；直接写入指定闪念笔记的锚点下方 |
| `Ctrl + Alt + T` | 保存待办 | 默认关闭；启用后生成 Obsidian Tasks 兼容任务 |
| `Ctrl + Alt + N` | 新建笔记 | 默认启用；创建独立笔记并默认在闪念笔记中插入链接 |

三个快捷键都可以在设置界面单独启用、关闭和修改；只有启用的快捷键才会注册为 Windows 全局热键。

## 3. Obsidian 写入基线

本项目参考 Android 项目 `D:\Codex-Temp\260606-android-dev`，复用其存入位置和主要 Markdown 结构。

- Obsidian Vault：`C:\OBS\Damon`
- 闪念目标笔记：`C:\OBS\Damon\【MOC】闪念-随手记.md`
- 默认插入锚点：`<!-- DABAWEI_FLASHNOTE_INBOX -->`，可在设置界面通过“修改”更新
- 插入位置：锚点正下方
- 内容顺序：最新记录在前
- 新建笔记默认目录：`C:\OBS\Damon\01-看板-日记-杂项`

Vault、目标笔记和新建笔记目录均可在设置界面选择。路径文本框为只读，不能直接键入修改；插入锚点同样只读，只能通过“修改”按钮更新。保存或测试配置时，程序要求该锚点在目标笔记中恰好出现一次。

## 4. 三种保存方式

### 4.1 普通闪念

```md
**大尾巴闪念-202608121530**
- 这是网页的第一行 #闪念  
  这是同一段的第二行

  这是网页的第二段  
  记录日期:: 2026-08-12 15:30
  来源网址:: https://example.com/article
  备注::
  ^flash-20260812-153000-pc
```

单换行在 Obsidian 中显示为换行，网页原有空行显示为段落间距。检测到网页来源时，普通闪念增加“来自`域名`网页的剪藏。”，例如“来自x.com网页的剪藏。”；没有检测到网页来源时，不生成该句和 `来源网址::` 字段。

### 4.2 待办

```md
**大尾巴闪念-202608121531**
- [ ] 整理这篇文章的要点 #闪念 #待办
  记录日期:: 2026-08-12 15:31
  任务ID:: pc-20260812153100-a1b2
  截止日期::
  提醒时间::
  来源网址:: https://example.com/article
  备注::
  ^flash-20260812-153100-pc
```

待办同样保留网页换行和段落，且仍是 Obsidian Tasks 可识别的单个未完成任务。v0.2.1 不自动推断截止日期和提醒时间。

### 4.3 新建笔记

按 `Ctrl + Alt + N` 后打开小窗口：

- 标题：根据剪贴板第一行自动建议，可修改。
- 正文：自动带入剪贴板原文，保留换行，可修改。
- 来源网址：自动识别，可修改或清空。
- 保存目录：使用设置中的默认目录，本次也可选择其他目录。

确认后创建独立 `.md` 文件；同名文件已存在时不覆盖，自动在文件名后追加时间。默认同时在闪念目标笔记的锚点下插入 `[[Vault 相对路径|笔记名]]` 可点击链接；该功能可在设置中关闭。若独立笔记已创建但链接回写失败，程序明确提示“笔记已创建，链接未写入”，不会误报为全部成功。

### 4.4 内容格式

设置界面提供三种互斥模式：

| 模式 | 适用场景 | 行为 |
| --- | --- | --- |
| 智能 Markdown | 网页文章、帖子、文档 | 保留段落和列表，将网页 `<strong>/<b>` 或 `font-weight:bold/600–900` 转换为 `**加粗**` |
| Markdown 代码块（当前默认） | 代码、Prompt、需要完整保留符号的文字 | 普通闪念使用顶格 `markdown` 围栏，长行折行与常规代码块对齐；待办继续嵌套在任务列表中 |
| 纯文本段落 | 只需要文字和换行 | 沿用 v0.2.1 的段落保留格式 |

加粗识别依赖剪贴板中存在网页 HTML 格式。如果来源软件只提供纯文本，程序不会凭字体或语义猜测加粗位置。

普通闪念的代码块结构如下，围栏、正文和元数据均不增加列表缩进：

````markdown
**大尾巴闪念-202608121530**
#闪念

```markdown
需要完整保留的正文
长行在 Obsidian 中自动折行时，折行前后保持同一左边界
```
记录日期:: 2026-08-12 15:30
来源网址:: https://example.com/article
备注::
^flash-20260812-153000-pc
````

## 5. 网页来源网址

如果剪贴板内容来自网页，程序按以下顺序获取来源网址：

1. 优先读取 Windows 剪贴板 HTML 数据中的 `SourceURL`。
2. 如果没有 `SourceURL`，且当前活动窗口是 Chrome、Edge 或 Firefox，则通过 Windows UI Automation 读取当前标签页网址，不改动剪贴板。
3. UI Automation 失败时，才临时复制浏览器地址栏作为最后兜底；操作前完整保存剪贴板，完成后原样恢复。
4. 只接受 `http://` 或 `https://` 网址。
5. 非网页内容不添加来源网址。

该能力不需要安装浏览器扩展。部分网页或软件只向剪贴板提供纯文本，也可能无法提供来源信息；程序不会凭当前网页猜测已经切换过窗口的剪贴板来源。

## 6. 简单 UI

主界面只保留必要内容：

- 运行状态和 AutoHotkey v2 环境状态。
- Vault 根目录、闪念目标笔记、新建笔记默认目录的只读路径及“选择”按钮。
- 只读插入锚点及“修改”按钮；锚点为空、缺失或重复时拒绝保存。
- 普通闪念、待办、新建笔记三组快捷键。
- 三组快捷键各自的启用开关；默认启用普通闪念和新建笔记，默认关闭保存待办。
- “自动附加网页来源网址”开关，默认开启。
- “无法从剪贴板取得时，从当前浏览器补取网址”开关，默认开启。
- “新建笔记后，在闪念笔记中插入可点击链接”开关，默认开启。
- “开机自启”开关，首次默认关闭。
- “内容格式”下拉框：智能 Markdown、Markdown 代码块、纯文本段落。
- “保存并应用”“测试配置”“使用说明”“隐藏到托盘”“打开笔记”“退出”按钮。

关闭主窗口只隐藏到托盘，不退出脚本。托盘菜单提供“打开设置、暂停/恢复快捷键、打开目标笔记、退出”。

## 7. 运行方式

1. 安装 AutoHotkey v2。
2. 双击 `03-Src\大尾巴闪念PC版.ahk`。
3. 首次启动显示设置界面，确认路径和快捷键。
4. 点击“保存并应用”；关闭主窗口只会隐藏到托盘，三个全局快捷键继续生效。
5. 用户可按需开启开机自启。

配置保存为项目目录下的 `config.ini`，使用 UTF-8 专用读写逻辑，中文路径不会被 Windows INI API 误转码。配置和日志都不保存剪贴板正文、完整网址、WebDAV 密码或其他账号凭据。

项目主要文件：

```text
03-Src/
  大尾巴闪念PC版.ahk       # 双击运行的主脚本
  lib/                       # 安全写入、UTF-8 配置、网页来源
config.ini                   # 当前本机配置
config.example.ini           # 默认配置示例
tests/                       # AHK 回归与真实 Vault 验收脚本
logs/flashnote-pc.log        # 不含正文和完整网址的运行日志
```

## 8. 当前范围

本版本包含：

- AutoHotkey v2 源码交付。
- 简单设置 UI 和托盘菜单。
- 普通闪念、待办、新建笔记三种快捷键。
- 网页来源网址识别和写入。
- Android 兼容的闪念格式。
- UTF-8 Markdown 安全写入、并发变化保护和结果提示。

本版本不包含：

- EXE 打包。
- 图片、附件、富文本和 HTML 正文保存。
- 大模型分类或摘要。
- 自动识别截止日期、提醒时间。
- WebDAV 账号或远程上传。
- 搜索和历史管理界面。
- macOS 版本。

## 10. GitHub 开源项目调研

本轮没有发现同时满足“AutoHotkey v2、系统级快捷键、直接安全写入指定 Obsidian 锚点、普通闪念、待办、新建笔记、自动来源网址、简单 UI”的现成项目。可参考的项目包括：

- [AutoHotkey/AutoHotkey](https://github.com/AutoHotkey/AutoHotkey)：官方运行环境和热键能力，GPL-2.0。
- [AHK v2 GetUrl()](https://gist.github.com/anonymous1184/7cce378c9dfdaf733cb3ca6df345b140)：使用 UI Automation/MSAA 读取浏览器网址，技术路线高度相关；页面未见明确许可证，不直接复制代码。
- [AHK v2 启动 Obsidian QuickAdd 示例](https://gist.github.com/ScottJWalter/e60a9ce137226fb88784537e4f510c26)：证明 AHK 可以用全局热键调用 Obsidian URI，但依赖 Obsidian、QuickAdd 和 Advanced URI，不采用该架构。
- [QuickAdd](https://github.com/chhoumann/quickadd)：成熟的模板、新建笔记和追加到指定文件设计，MIT；仅作为交互和模板参考。
- [Obsidian Web Clipper](https://github.com/obsidianmd/obsidian-clipper)：官方网页捕获项目，MIT；参考来源网址和 Markdown 元数据设计，不引入浏览器扩展。

结论：保留本项目的独立 AHK 方案，借鉴成熟项目的行为设计；只有许可证明确且确有必要的代码才允许复用并记录出处。
