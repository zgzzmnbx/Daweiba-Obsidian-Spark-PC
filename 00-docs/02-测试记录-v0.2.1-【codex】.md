> 结论：已修复。

## 新格式

```md
- 第一段第一行 #闪念  
  第一段第二行

  第二段  
  记录日期:: 2026-08-12 15:30
  来源网址:: https://example.com/article
  备注::
  ^flash-20260812-153045-pc
```

- 每个非空续行保持两个空格缩进，仍属于同一列表项。
- 单换行使用 Markdown 行尾两空格生成硬换行。
- 一个或多个空行归一为一个段落间隔。
- 待办使用相同规则，首行仍为 `- [ ]`，不影响 Obsidian Tasks 识别。
