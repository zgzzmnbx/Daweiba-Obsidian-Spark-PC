## 4. 验收重点

1. 三组快捷键在 Windows 任意常用软件前台时均可触发。
2. 普通闪念和待办准确写入设置中指定的唯一锚点正下方。
3. 新建笔记可编辑标题、正文、来源网址和保存目录，且不覆盖同名文件。
4. Chrome、Edge、Firefox 来源网址按“SourceURL → UI Automation → 地址栏复制兜底”工作。
5. 非网页复制不误加网址。
6. 地址栏读取后完整恢复原剪贴板。
7. Obsidian 打开或关闭时均能保存。
8. 任何异常和多端并发都不损坏原笔记。
9. 三条路径和插入锚点不能在主界面直接键入修改，只能使用对应按钮更新。
10. 普通闪念代码块中的长行在 Obsidian 自动折行时，折行前后使用同一左边界。
11. 首次运行只注册普通闪念和新建笔记两个快捷键；保存待办默认不占用全局热键。
12. 新建笔记成功后，闪念目标笔记出现可点击的 Vault 相对链接；关闭回链开关时不写入。
13. 网页普通闪念显示可靠来源域名，不从正文或当前无关页面猜测来源。
