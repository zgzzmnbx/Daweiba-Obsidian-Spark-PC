# 大尾巴闪念 PC 版 v0.3.3 测试记录

> 日期：2026-08-12  
> 环境：Windows / AutoHotkey v2.0.26  
> 结论：通过

## 1. 问题复现

旧版普通闪念把围栏代码块嵌套在 `- #闪念` 下，每个物理行带两个空格。Obsidian 对长行自动折行时，续行不继承这两个源码空格，造成首行偏右、折行突然向左的视觉差异。

## 2. 修复结果

- 普通闪念使用顶格 `#闪念`。
- 普通闪念的 `markdown` 围栏、正文、日期、来源网址、备注和块 ID 全部顶格。
- 待办继续使用 `- [ ] #闪念 #待办`，围栏和字段保持两个空格缩进。
- 已有历史闪念不自动改写；修复只影响 v0.3.3 之后新保存的内容。
